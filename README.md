# Websitenostrbased

Personal / professional marketing site (Vite + React). Optional Nostr profile sync via `npub` in config.

## Quick start

```bash
npm install
npm run dev
```

## Personalize

Edit [`src/config/site.ts`](src/config/site.ts) for copy, stats, services, blog cards, links, and `npub`.

## GitHub

Remote: `https://github.com/Gmuney/Websitenostrbased`

## Production

```bash
npm run build
```

Deploy the `dist/` folder to your static host.
